BLOQUE 1

🧁 Conceptos básicos de la sintaxis en Python

Antes de sumergirnos en conceptos más avanzados, es importante familiarizarse con algunos aspectos básicos de la sintaxis de Python.

📐 Indentación

En Python, la indentación (espacios o tabulaciones al inicio de una línea) se utiliza para delimitar bloques de código. A diferencia de otros lenguajes que usan llaves { } o palabras clave, Python usa la indentación para determinar el alcance de las declaraciones.

if condition:
    # Bloque de código si la condición es verdadera
    instrucción1
    instrucción2
else:
    # Bloque de código si la condición es falsa
    instrucción3
    instrucción4
⚠️
Importante: es fundamental mantener una indentación consistente en todo el código para evitar errores de sintaxis.

🔤 Sensibilidad a mayúsculas y minúsculas

Python distingue entre mayúsculas y minúsculas. Por lo tanto, variable, Variable y VARIABLE se consideran variables diferentes.

🪄 Punto y coma

A diferencia de otros lenguajes, Python no requiere el uso de punto y coma ; al final de cada instrucción. Sin embargo, si querés escribir varias instrucciones en una sola línea, podés separarlas con un punto y coma.

instruccion1; instruccion2; instruccion3

🍥 Uso de paréntesis

Los paréntesis se utilizan para agrupar expresiones, definir funciones y realizar llamadas a funciones.

resultado = (a + b) * c
🌟
Extra complementario: aunque no es obligatorio, casi toda la comunidad Python sigue la guía de estilo PEP 8, que recomienda usar 4 espacios (no tabulaciones) para cada nivel de indentación. Adoptar esta costumbre desde el principio evita errores raros de "unindent" más adelante 🐣.

BLOQUE 2

🍭 Fundamentos de Python

Tipos de datos básicos: las categorías en las que se clasifican los valores que usamos en nuestros programas. Comprenderlos es fundamental para trabajar con variables y realizar operaciones en Python.

🔢 Enteros (int)

Los números enteros son aquellos que no tienen parte decimal. En Python, se representan simplemente escribiendo el número sin comillas ni puntos decimales.

edad = 25
cantidad = 100

🌊 Flotantes (float)

Los números flotantes, también conocidos como números de punto flotante, son aquellos que tienen una parte decimal. Se representan utilizando un punto para separar la parte entera de la parte decimal.

precio = 9.99
altura = 1.75

💬 Cadenas de texto (strings)

Las cadenas de texto, o simplemente cadenas, son secuencias de caracteres encerradas entre comillas simples '...' o dobles "...". Se utilizan para representar texto en Python.

nombre = "Juan"
mensaje = '¡Hola, mundo!'

🔘 Booleanos

Los valores booleanos representan los valores de verdad: True (verdadero) y False (falso). Se utilizan comúnmente en expresiones condicionales y operaciones lógicas.

es_mayor_de_edad = True
tiene_descuento = False
📝
Ten en cuenta: los valores booleanos en Python comienzan con una letra mayúscula: True y False.

📛 Normas para nombrar variables

Al nombrar variables en Python, es importante seguir algunas normas para mantener un código legible y evitar errores:

🔸 Los nombres solo pueden contener letras (a-z, A-Z), números (0-9) y guiones bajos (_). No pueden comenzar con un número.
🔸 Python distingue entre mayúsculas y minúsculas.
🔸 No se pueden utilizar palabras clave reservadas de Python como nombres de variables.

Nombres válidos ✅:

edad
nombre_completo
total_ventas

Nombres inválidos ❌:

1edad

🚦 Estructuras de control

Las estructuras de control nos permiten controlar el flujo de ejecución de nuestros programas.

1️⃣ IF

edad = 18

if edad >= 18:
    print("Eres mayor de edad.")

2️⃣ IF-ELSE

edad = 15

if edad >= 18:
    print("Eres mayor de edad.")
else:
    print("Eres menor de edad.")

3️⃣ IF-ELIF-ELSE

calificacion = 85

if calificacion >= 90:
    print("Excelente")
elif calificacion >= 80:
    print("Muy bueno")
elif calificacion >= 70:
    print("Bueno")
else:
    print("Necesita mejorar")

BLOQUE 3.1

🔁 Bucles / loops

Los bucles nos permiten repetir un bloque de código varias veces.

🍎 For

frutas = ["manzana", "banana", "naranja"]

for fruta in frutas:
    print(fruta)

⏳ While

contador = 0

while contador < 5:
    print(contador)
    contador += 1

🛑 Break

contador = 0

while True:
    print(contador)
    contador += 1

    if contador == 5:
        break

⏭️ Continue

for i in range(10):
    if i % 2 == 0:
        continue
    print(i)

🌫️ Pass

for i in range(5):
    pass

BLOQUE 5

🧩 Funciones

Las funciones son bloques de código reutilizables que nos permiten encapsular tareas específicas.

📣 Definición y llamada de funciones

def saludo():
    print("¡Hola, mundo!")

saludo()  # Imprime "¡Hola, mundo!"

🎁 Parámetros y argumentos

def saludo(nombre):
    print(f"¡Hola, {nombre}!")

saludo("Juan")   # Imprime "¡Hola, Juan!"

↩️ Valores de retorno

def suma(a, b):
    return a + b

resultado = suma(3, 4)
print(resultado)  # Imprime 7

🪶 Funciones anónimas (lambda)

cuadrado = lambda x: x ** 2
print(cuadrado(5))  # Imprime 25

BLOQUE 6

🚨 Manejo de errores y excepciones

Python proporciona un mecanismo para manejar estos errores de manera controlada utilizando el manejo de excepciones.

🐞 Errores comunes en Python

SyntaxError: El código no sigue las reglas de sintaxis de Python.
NameError: Se hace referencia a una variable o función que no ha sido definida.
TypeError: Se realiza una operación con tipos de datos incompatibles.
IndexError: Se intenta acceder a un índice fuera del rango válido.

🎣 Try

try:
    resultado = 10 / 0
    print(resultado)
except ZeroDivisionError:
    print("Error: División por cero")

🧹 Finally

try:
    archivo = open("archivo.txt", "r")
except FileNotFoundError:
    print("Error: Archivo no encontrado")
finally:
    archivo.close()
