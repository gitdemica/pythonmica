🧁 Conceptos básicos de la sintaxis en Python

Antes de sumergirnos en conceptos más avanzados, es importante familiarizarse con algunos aspectos básicos de la sintaxis de Python.

📐 Indentación

En Python, la indentación (espacios o tabulaciones al inicio de una línea) se utiliza para delimitar bloques de código. A diferencia de otros lenguajes que usan llaves { } o palabras clave, Python usa la indentación para determinar el alcance de las declaraciones.

if condition:
    # Bloque de código si la condición es verdadera
    instrucción1
    instrucción2
else:
    # Bloque de código si la condición es falsa
    instrucción3
    instrucción4
⚠️
Importante: es fundamental mantener una indentación consistente en todo el código para evitar errores de sintaxis.

🔤 Sensibilidad a mayúsculas y minúsculas

Python distingue entre mayúsculas y minúsculas. Por lo tanto, variable, Variable y VARIABLE se consideran variables diferentes.

🪄 Punto y coma

A diferencia de otros lenguajes, Python no requiere el uso de punto y coma ; al final de cada instrucción. Sin embargo, si querés escribir varias instrucciones en una sola línea, podés separarlas con un punto y coma.

instruccion1; instruccion2; instruccion3

🍥 Uso de paréntesis

Los paréntesis se utilizan para agrupar expresiones, definir funciones y realizar llamadas a funciones.

resultado = (a + b) * c
🌟
Extra complementario: aunque no es obligatorio, casi toda la comunidad Python sigue la guía de estilo PEP 8, que recomienda usar 4 espacios (no tabulaciones) para cada nivel de indentación. Adoptar esta costumbre desde el principio evita errores raros de "unindent" más adelante 🐣.
